# LittleTidy 0.8.3

- Added Project Build Folders detection across 20+ ecosystems (`.build`, `target`, `build`, `cmake-build-*`, `.gradle`, `node_modules`, `.next`, `.venv`, `Pods`, `Carthage/Build`, Unity `Library`, Unreal `Intermediate`, and `CACHEDIR.TAG` directories), verified via sibling project manifests and protected by open-file checks.
- Expanded macOS cache discovery to include Group Container cache subdirectories, `HTTPStorages/fsCachedData`, WebKit network and cache storage, saved application states, app logs, creative/media caches (Adobe, Spotify, Steam), and Electron/Chromium GPU, shader, code, and service-worker caches.
- Expanded Developer Storage with multi-platform Xcode DeviceSupport (`watchOS`, `tvOS`, `visionOS`, `macOS`, `CoreDeviceData`), 45+ package manager and build caches, and additional AI model and IDE cache locations.

Requires macOS 26 or later.
