# LittleTidy 0.6.0

- More accurate reclaimable-space estimates based on allocated disk usage, with hard-linked files counted only once.
- New AI storage categories for models, recreatable caches and logs, and reviewable sessions and generated artifacts.
- Safer, clearer Developer Storage recommendations with selected cleanup candidates shown first.
- Improved Overview and Cleanup Plan flows so each recommendation opens the correct cleanup mechanism.
- Faster analysis through safe parallel processing of independent scanners.
- Native JSON-based Xcode project format for more readable and merge-friendly project changes.
