# LittleTidy 0.7.0

- New System Diagnosis explains application containers, shared app data, developer resources, and known protected system storage. Unknown measurements remain visible, and reports can be exported as JSON.
- Explore storage one folder at a time, with progressive sizes and clear labels for caches, build output, Git checkouts, and application or personal data.
- Review registered agent worktrees with branch, size, local and ignored file checks, and an open-file activity snapshot. Removal requires explicit permanent-deletion opt-in, confirmation, and fresh checks; Git is never forced and the branch is preserved.
- New Maintenance view inventories startup services and reports Spotlight and Time Machine snapshot status. An optional signed administrator service supports confirmed DNS refresh and Spotlight reindexing.
- New Protection view checks Gatekeeper, FileVault, System Integrity Protection, and the application firewall, and assesses selected applications with Gatekeeper. These checks are not an antimalware engine.
- Improved recognition of temporary Claude build output, compact-window layouts, accessibility, and complete app-bundle packaging.

Requires macOS 26 or later. The administrator service requires macOS approval; Full Disk Access is separate. Agent activity checks are snapshots: stop the owning agent and archive associated tasks before removing a worktree. DNS refresh, Spotlight rebuilding, and administrator-service removal have not yet been exercised end to end.
