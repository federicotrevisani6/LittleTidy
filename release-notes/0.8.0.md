# LittleTidy 0.8.0

- XCTest clones that Xcode creates for parallel testing are now recommended for cleanup and removed with `simctl`. While a test run is active, every clone is protected until it finishes.
- Developer cleanup no longer stops entirely while Xcode is open. Build data of projects that are not open, and Simulator devices nothing is using, can be cleaned; everything else Xcode owns waits until you quit it. Derived Data is now listed per project.
- Sizes now show how much space is freed right away. Simulator clones share storage, and a Time Machine local snapshot keeps older data until macOS releases it, so the app shows "at least X freed right away" and explains when a snapshot is holding space.
- After a cleanup, you can ask macOS to release the space a local snapshot still holds. macOS removes local snapshots, oldest first, until that space is reclaimed; backups on a Time Machine disk are not affected.
- Old Homebrew versions and downloads are estimated with `brew cleanup --dry-run` and reclaimed with `brew cleanup`.
- Cleanup results show the total removed, the measured change in free space, what is still in the Trash, and the reason for every skipped or failed item. Removed items leave the list immediately.
- Fixed: the deletion mode chosen in Settings now applies without relaunching, and is no longer overwritten by the previous value. Cleanup wording now matches permanent-delete mode.
- Fixed: symbolic links, such as `~/.swiftpm/cache`, are no longer offered for cleanup.

Requires macOS 26 or later. Releasing snapshot space removes local hourly restore points and cannot be undone. Homebrew cleanup requires Homebrew in `/opt/homebrew` or `/usr/local`.
