# LittleTidy 0.8.2

- Fixed: permanent deletion no longer stops halfway when a folder contains files owned by another user (such as root, or an account that no longer exists) or locked files. LittleTidy now checks first and moves such folders to the Trash instead, explaining why; Finder asks for an administrator password when you empty the Trash. This affected, for example, downloaded Codex updates and some Xcode build folders.

Requires macOS 26 or later.
