# LittleTidy 0.8.1

- Temporary folders of closed Claude sessions (screenshots, videos, builds, and scratch files) are now offered for cleanup, one item per session. Running sessions are never offered, and each session is checked again right before cleanup. Conversation transcripts are kept.
- Codex and Antigravity caches, including downloaded app updates, are now recognized. AI app caches are cleaned only when no app has files open inside them.
- Simulator devices now include the OS version in their name, so the same model on two runtimes no longer looks duplicated.
- Empty items, such as XCTest clones whose folder is already gone, are no longer preselected.
- The Overview total no longer counts space that Simulator clones share with their source device.
- Developer Storage scans finish sooner: the Homebrew estimate runs alongside the rest of the scan.

Requires macOS 26 or later.
